# Рядом

Мессенджер для браузера: https://ryadom-messenger.pugnu.chatgpt.site

Регистрация по нику и паролю, личные чаты, группы, профили, фото, файлы, голосовые сообщения и видеокружки. В кружке можно переключать переднюю и заднюю камеры во время одной записи; звук сохраняется. Если второй камеры нет, приложение возвращается к прежней.

## Разработка

Нужен Node.js 24.

```sh
npm ci
npm test
npm run build
```

- `src/index.html` — оформление и HTML-каркас.
- `src/client.js` — интерфейс и запросы к API.
- `src/icons.js` — значки и DOM-помощники.
- `src/round-camera.js` — непрерывная запись с переключением камер.
- `src/server.js` — Cloudflare Worker, авторизация и API.
- `db/schema.ts` и `drizzle/` — структура D1 и миграции.
- `scripts/build.mjs` — собирает сервер и встраивает клиент в HTML.
- `tests/` — проверки аккаунтов, прав доступа и переключения камер.

## Развёртывание

Это приложение с сервером, а не статическая страница GitHub Pages. Рабочий сайт размещён через Sites. Для сервера нужны привязки Cloudflare D1 `DB` и R2 `BUCKET`; схема создаётся миграциями из `drizzle/`. Сборка создаёт `dist/server/index.js` с `fetch`-обработчиком. Обновление репозитория само по себе не обновляет действующий сайт: его публикация выполняется отдельно.

Не загружать в GitHub базы, пользовательские файлы, пароли, коды восстановления, токены, cookies или `.env`.

## Текущее состояние

- Файлы до 20 МБ, до 250 МБ на аккаунт.
- Сообщения обновляются опросом сервера каждые 4 секунды при открытой вкладке.
- Восстановление доступа по коду, полученному при регистрации.
- Камера и микрофон требуют HTTPS и разрешения браузера.
- Проверки камеры используют имитацию устройств; работа с реальными камерами зависит от браузера и телефона.
- Сквозное шифрование, push-уведомления и Android APK пока не реализованы.
